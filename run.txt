2. MASTER ORCHESTRATION SCRIPTS (PowerShell)
================================================================================
These scripts manage the entire environment lifecycle (located in `scripts/`).

A. [LAUNCH] LAUNCH_NEXUS.PS1
   The primary entry point for bootstrapping the full stack.
   Parameters:
   - -RunMode: [MOCK | LIVE | HYBRID | DAEMON]
   - -ForceRebuild: Repulls Docker images and wipes caches.
   - -VerboseUI: Enables detailed terminal output for orchestrator stages.

   Common Commands:
   > .\scripts\launch_nexus.ps1 -RunMode MOCK
   > .\scripts\launch_nexus.ps1 -RunMode LIVE -ForceRebuild
   > .\scripts\launch_nexus.ps1 -RunMode HYBRID -VerboseUI

B. [PURGE] SOFT_RESET.PS1
   Gracefully stops Docker containers, flushes Redis cache, kills
   orphan Python processes, and rotates logs.
   > .\scripts\soft_reset.ps1
   > .\scripts\soft_reset.ps1 -ForceTerminate

C. [DESTRUCT] HARD_RESET.PS1
   Irreversibly destroys all containers, volumes, databases, venv,
   pycache, and forensic logs. Use with extreme caution.
   > .\scripts\hard_reset.ps1
   > .\scripts\hard_reset.ps1 -BypassConfirmation

10. TROUBLESHOOTING & FAQ
================================================================================
SYMPTOM: "Neo4j connection refused after hard reset."
CAUSE:  Plugin directory initialization race condition.
FIX:    Wait 30 seconds for GDS to bootstrap and check `docker logs`.

SYMPTOM: "Simulation drift produces zero Risk-Delta."
CAUSE:  The mutation target was already in a compromised state.
FIX:    Run `mesh_seeder.py --clean` and re-seed the baseline.

SYMPTOM: "Memory exhaustion in backend orchestrator."
CAUSE:  Large topology discovery (10k+ nodes) without --no-simulation.
FIX:    Increase system swap or disable predictive blast radius.

SYMPTOM: "Timeline playback shows disconnected nodes."
CAUSE:  Forensic ledger entry received out-of-order.
FIX:    The Reconstructor will self-heal during the next scan cycle.

SYMPTOM: "Absolute Safety Kernel blockage."
CAUSE:  Unauthorized API mutation detected by the security trap.
FIX:    Consult the SimulationStudio policy to verify intended behavior.
